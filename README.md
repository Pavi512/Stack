# Stack

A Java console-based application that demonstrates the implementation of the Stack data structure using Linked Lists and Object-Oriented Programming. The project implements the fundamental Stack operations following the LIFO (Last In, First Out) principle. Each use case is developed in a separate feature branch and merged into the development branch using a Git feature branch workflow.

---

## About the Project

A Stack is a linear data structure that follows the Last In, First Out (LIFO) principle, where the last element inserted is the first one to be removed.

This project demonstrates how to implement a Stack using a Linked List in Java. It covers the core Stack operations such as push, pop, and peek while maintaining LIFO ordering. The implementation follows Object-Oriented Programming principles and uses custom node structures instead of Java Collection classes.

The implemented use cases are based on the BridgeLabz Data Structure using Java Generics module and are developed incrementally using a Git feature branch workflow.

## Git Workflow

The project follows a feature branch workflow.

- `main` – Initial project setup
- `dev` – Development branch
- `feature/UC1`
- `feature/UC2`

Each feature branch introduces a Stack operation. After implementation and testing, the feature branch is merged into the `dev` branch, ensuring incremental development and a clean Git history.
